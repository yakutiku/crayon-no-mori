# クレヨンのもり

3歳ごろの子どもが、待ち時間に音なしでも静かに遊べる Web アプリ（PWA）です。広告・課金・外部への通信・個人情報の取得はありません。お絵かきの絵も保存しません。設定だけを端末の中に保存します。

公開URL: https://yakutiku.github.io/crayon-no-mori/

## 遊び

- いろあわせ：同じ色のものを選ぶ
- かたちあわせ：同じ形を選ぶ
- おおきい・ちいさい：大きさをくらべる
- ながい・みじかい：長さをくらべる
- どうぶつ いないいないばあ：動物がかくれて、あらわれる
- おえかき：クレヨンで自由に描く
- ろうそく ふーっ：ろうそくの火を、ふーっと消す

×や点数、時間制限はありません。まちがえたときは、ものがゆっくり元に戻るだけです。

## 音

初期設定は音なしです。保護者設定で効果音や声をオンにできます。声は端末の読み上げ機能を使うため、端末によっては日本語の声がありません。

## ホーム画面への追加

- iPhone：Safari で開き、共有ボタン →「ホーム画面に追加」
- Fire HD 10：Silk で開き、メニュー →「ホーム画面に追加」または「アプリをインストール」

一度開けば、電波がなくても遊べます。

## 保護者設定

ホーム画面右上の葉っぱの印を3秒押し続けると開きます。

## ファイル構成

- `index.html`：入口のページ
- `manifest.webmanifest`：ホーム画面に追加するための設定
- `sw.js`：オフラインで遊ぶためのサービスワーカー
- `icons/`：アプリのアイコン
- `src/core`：色・設定・音・読み上げなど共通の部品
- `src/art`：絵の部品
- `src/games`：各遊び
- `src/parent`：保護者設定と「保護者の方へ」ページ
- `tests/`：動作確認のテスト（公開しない）
- `tools/`：開発用のスクリプト（公開しない）

## 開発者向け

動作確認のテスト：

```
node tests/<名前>.test.mjs
```

アイコンの書き出し（`src/core/palette.js` の色を使います）：

```
node tools/make-icons.mjs
```

公開されるファイルの大きさの集計：

```
node tools/size.mjs
```
